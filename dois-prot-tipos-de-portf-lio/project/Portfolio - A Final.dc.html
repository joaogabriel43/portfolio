EM DESTAQUE

AuditVault

Um motor de auditoria que se acopla a qualquer API REST sem que o código de negócio saiba que está sendo auditado.

0ms LATÊNCIA ADICIONAL
O(1) CUSTO DE LEITURA
50 EVENTOS / SNAPSHOT
25s HEARTBEAT SSE
DECISÃO 01 AOP com @Auditable

Interceptadores capturam as mutações de estado automaticamente. Zero intrusão, ofuscação de PII aplicada nos campos marcados.

DECISÃO 02 Snapshots a cada 50 eventos

Event Sourcing puro lê em O(N). Consolidar o estado periodicamente limita a reconstrução a 50 iterações — O(1) na prática.

DECISÃO 03 SSE em vez de WebSocket

O fluxo é unidirecional. Um ping a cada 25s mantém a conexão viva atrás de proxies e load balancers.
