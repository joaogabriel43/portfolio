SISTEMA 03 / MENSAGERIA / 2025

NotifyFlow

Motor de notificações multi-canal com garantia de entrega. Se o EMAIL falha, tenta SMS. Se o SMS falha, tenta PUSH. Nenhuma mensagem se perde entre o banco e o broker.

O PROBLEMA

Salvar no banco e publicar no broker em sequência abre uma janela de falha: se o processo cai entre as duas operações, a mensagem se perde ou duplica — e não há como reconciliar depois.

SISTEMA 02 / AUDITORIA / 2025

AuditVault

Event Sourcing plug-and-play. Captura toda mutação de estado de uma API REST via AOP e reconstrói o estado de qualquer entidade em qualquer ponto do passado.

O PROBLEMA

"Quem alterou o registro X, quando e por quê?" normalmente termina em logs caóticos e acoplados à regra de negócio. E Event Sourcing puro lê em O(N) — degrada silenciosamente conforme a entidade acumula histórico.
